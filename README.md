# Professional-Survey-Breakdown-Dashboard

## Overview

This Power BI dashboard analyzes survey responses from data professionals around the world to uncover insights into salaries, job roles, programming language preferences, career satisfaction, and challenges faced while entering the data industry.

The goal of this project is to transform raw survey data into meaningful visual insights that help understand current trends in the data analytics field.

---

## Tools & Technologies

* Power BI Desktop
* Power Query
* Microsoft Excel (Dataset Source)

---

## Dataset

The dataset contains survey responses from professionals working in various data-related roles, including Data Analysts, Data Scientists, Data Engineers, and other technology professionals.

Key information available in the dataset includes:

* Country of respondents
* Job titles
* Annual salary
* Favorite programming language
* Work-life balance rating
* Salary satisfaction rating
* Difficulty of entering the data field

---

## Dashboard Highlights

### Data Preparation

* Cleaned and transformed survey data using Power Query.
* Standardized values and handled inconsistencies to improve data quality.

### Key Insights

#### Survey Participation

Displays the total number of survey respondents and their geographic distribution across different countries.

#### Salary Analysis

Compares average salaries across job roles, helping identify compensation trends within the data industry.

#### Programming Language Preferences

Shows the most commonly used programming languages among survey participants and highlights differences across job positions.

#### Entry into Data Analytics

Analyzes respondents' opinions on how difficult it is to break into the data field.

#### Career Satisfaction

Measures employee satisfaction through work-life balance and salary satisfaction scores.

---

## Business Value

This dashboard helps:

* Understand salary trends across data-related careers.
* Identify popular technical skills and programming languages.
* Explore employee satisfaction levels within the industry.
* Gain insights into challenges faced by aspiring data professionals.
* Support career planning and industry research through data-driven analysis.
